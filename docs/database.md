# Database

PostgreSQL (Neon) via Drizzle ORM, schema-first. Schema files live in
`db/schema/` (one file per concern), re-exported from `db/schema/index.ts`.
Migrations are generated with `pnpm db:generate` into `db/migrations/` and must
be committed.

- `db/schema/auth.ts` — **generated** by Better Auth (`pnpm auth:generate`). Do
  not hand-edit; change `lib/auth.ts` and regenerate.
- `db/schema/salon.ts` — domain tables (hand-written).
- `db/schema/_shared.ts` — shared column helpers (`timestamps`).

## Auth & tenancy tables (Better Auth)

Generated by the Better Auth `organization` plugin (teams enabled).

| Table          | Purpose                                                     |
| -------------- | ----------------------------------------------------------- |
| `user`         | Accounts (id, name, email, emailVerified, image, `platform_admin`) |
| `session`      | Sessions; includes `activeOrganizationId`, `activeTeamId`   |
| `account`      | Credentials / provider accounts (password hash lives here)  |
| `verification` | Email/token verification records                            |
| `organization` | Empresa / cadena (top-level tenant); unique `slug`          |
| `team`         | **Salón (sede)** within an organization                     |
| `team_member`  | Links a user to a salón                                     |
| `member`       | User + `role` within an organization (default `member`)     |
| `invitation`   | Pending invites (email, role, optional `teamId`, status)    |

Roles in `member.role` (refined later via access control): `owner`, `admin`,
`manager`, `cashier`, `staff`.

## Domain tables

### `salon_settings`

Per-salón accounting configuration. One row per `team`.

| Column        | Type                      | Notes                                  |
| ------------- | ------------------------- | -------------------------------------- |
| `id`          | text (uuid)               | PK                                     |
| `team_id`     | text → `team.id` cascade  | Unique (one settings row per salón)    |
| `currency`    | text, default `USD`       | ISO currency code                      |
| `tax_rate`    | numeric(5,4), default `0` | Decimal rate, e.g. `0.1900` = 19%      |
| `timezone`    | text, default `UTC`       | IANA timezone                          |
| `address`     | text, nullable            |                                        |
| `phone`       | text, nullable            |                                        |
| `logo_url`    | text, nullable            | Shown on the printed receipt           |
| `created_at`  | timestamp                 | from `timestamps` helper               |
| `updated_at`  | timestamp                 | auto-updates on write                  |

| Column            | Type                       | Notes                          |
| ----------------- | -------------------------- | ------------------------------ |

| `organization_id` | text → `organization.id`   | cascade                        |
| `salon_id`        | text → `team.id`           | cascade; indexed               |
| `client_id`       | text → `client.id`         | nullable; on delete set null   |
| `status`          | text, default `completed`  | `completed` \| `void`          |
| `subtotal`        | numeric(12,2)              | sum of line totals             |
| `tax_rate`        | numeric(5,4)               | snapshot from `salon_settings` |
| `tax_amount`      | numeric(12,2)              | `subtotal * tax_rate`          |

| `notes`           | text, nullable             |                                |
| `created_at` / `updated_at` | timestamp        | from `timestamps`              |

| `difference`      | numeric(12,2), nullable  | counted − expected             |
| `notes`           | text, nullable           |                                |
| `created_at` / `updated_at` | timestamp      | from `timestamps`              |

## Conventions

- **Money**: never floats. Tax rate is `numeric`. Future amount columns use
  integer minor units or `numeric`.
- **Timestamps**: every table spreads `...timestamps` from `_shared.ts`
  (`created_at`, `updated_at`). Better Auth tables carry their own equivalents.
- **Tenancy**: future accounting tables must carry `organization_id` and a salón
  reference (`team_id`).

## Migrations

```bash
pnpm db:generate   # diff schema → new SQL migration
pnpm db:migrate    # apply migrations to DATABASE_URL
pnpm db:push       # push schema without a migration (dev only)
pnpm db:studio     # browse data
```

Migrations `0000`–`0009` applied to Neon. Tables: auth + tenancy (`user` with
`platform_admin`, `session`, `account`, `verification`, `organization`, `team`,
`team_member`, `member`, `invitation`) plus domain (`salon_settings`, `client`,
`service_category`, `service`, `sale`, `sale_item`, `payment`, `cash_session`,
`cash_movement`, `expense_category`, `expense`, `commission_rule`).

## Seeding

`pnpm db:seed` (`db/seed.ts`) bootstraps the first admin (public sign-up is
disabled): creates the user + credential account via Better Auth internals, then
one `organization`, `member` (role `owner`), `team` (salón), `team_member`, and
`salon_settings`. Idempotent (skips if the admin email exists). Override defaults
with `SEED_ADMIN_EMAIL`, `SEED_ADMIN_PASSWORD`, `SEED_ADMIN_NAME`,
`SEED_ORG_NAME`, `SEED_SALON_NAME`.
